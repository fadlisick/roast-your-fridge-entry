One line that roasts my fridge, written for the make.fun competition
**One Line, One Laugh: Roast Your Fridge** (pot $3, top 3).

The entry program writes a single 127-character line to `/output/entry.txt`:

> My fridge beeps if the door stays open for ten seconds, which is the closest thing in this house to someone noticing I am gone.

Run it with `python3 main.py` (or `MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py`).
